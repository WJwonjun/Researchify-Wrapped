이 Mac과 원격 서버들의 Claude Code 세션 로그를 정리해 주간 리서치 노트 허브에 올린다.
허브: {{HUB_URL}}
원격 서버의 로그는 이 Mac이 6시간마다 가져와 작업 폴더의 cc-log/ 에 합쳐 둔다.

1. 작업 폴더의 last-pull.txt 를 읽어 마지막으로 가져온 시각과 실패한 서버를 확인한다.
2. cc-log/ 아래에서 가장 최근 주차 폴더 2개의 .md 파일을 읽고, 첫 줄의 시각(시간대 포함)을 {{TZ_NAME}}으로 바꿨을 때 지금부터 7일 전 ~ 지금에 드는 것만 쓴다.
   파일 이름은 "<호스트>-<세션 8자>.md"이고, 마지막 하이픈 앞부분이 호스트다.
3. 호스트별로, 그 안에서 프로젝트(첫 줄의 폴더 이름)별로 묶어 아래 형식으로 줄인다.
   ## <프로젝트>
   - 다룬 작업: 1~2줄
   - 내 질문 원문: "왜", "어떻게" 류 문장을 그대로 인용 (최대 5개)
   - 반복된 에러: 같은 유형이 2번 이상 나온 것 (최대 3개, 각 1줄)
   - 자주 수정한 파일: 최대 5개
4. 연구·엔지니어링과 무관한 개인적인 내용, 키·토큰·비밀번호처럼 보이는 값은 적지 않는다.
5. Artifact 도구로 허브에 쓴다: action "write_db", url은 위 허브, db_op "batch", 호스트마다 문서 하나씩
   {"op": "set", "collection": "cclog", "doc_id": "<주차>--<호스트>", "data": {"week": "<주차>", "host": "<호스트>", "period": "YYYY-MM-DD ~ YYYY-MM-DD", "sessions": <세션 수>, "text": "<3의 정리>"}}
   - 주차는 오늘 날짜({{TZ_NAME}})의 ISO 주차다. 예: 2026-W47
   - 이 구간에 세션이 없는 호스트는 쓰지 않는다. text는 문서당 200 KB를 넘기지 않는다.
6. 파일은 읽기만 하고, 만들거나 지우지 않는다.
7. 실행 결과 마지막에 한 줄을 남긴다: "cclog: 호스트 H개, 세션 M개 / 마지막 가져오기 <시각> / 가져오기 실패: <서버 목록 또는 없음>"
8. Artifact 도구를 쓸 수 없으면 결과에 "Artifact 도구 없음"이라고 한 줄 남기고 멈춘다.
