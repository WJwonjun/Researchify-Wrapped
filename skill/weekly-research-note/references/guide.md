# 주간 리서치 노트 글쓰기·그림 가이드

이 문서는 매주 작업이 고쳐 쓰는 살아 있는 가이드다. 허브의 skill/guide가 최신본이고, 이 파일은 허브를 못 읽을 때 쓰는 기본본이다.

## 쓰기 규칙

- **제목은 주장 한 문장.** 이번 호의 꼭지들을 관통하는 통찰을 쓴다. 주제 나열("이번 주 RL 소식")은 쓰지 않는다.
- **섹션 제목도 주장.** 좋은 예: "ring all-reduce는 노드가 늘어도 각자 보내는 양이 거의 늘지 않는다". 나쁜 예: "Ring all-reduce 소개". 하위 제목(`1-B.1 ...`)도 같다.
- **문단 리듬은 주장 → 근거 → 직관.** 근거는 수식·그림·숫자 중 하나로 보이고, 바로 다음 문단을 "직관은 이렇습니다."처럼 쉬운 말 풀이로 시작한다.
- **합니다체**로 쓰고, 전문 용어는 처음 나올 때 원어를 함께 적는다. 인용 부호는 “ ”를 쓴다.
- **한눈에 보기**: 2~3문단 요약 + 카드 4장. 카드 값은 숫자·짧은 식·10자 이내 키워드이고, note 끝에 해당 섹션 번호를 괄호로 단다. 이번 실행에서 출처를 확인한 숫자만 쓴다.
- 논문을 언급하면 반드시 `references`에 넣는다.

## 그림 규칙

```python
import figstyle as fs              # 0단계에서 정한 figstyle.py (허브 최신본 또는 기본본)
fs.setup()                         # False를 돌려주면 한글 폰트가 없는 것 → 라벨을 영어로
fig, ax = fs.figure(ratio=0.5)
...
fs.save(fig, "fig1.svg")
fs.equation(r"\sigma = \frac{\sqrt{k\,(G-k)}}{G}", "eq1.svg")   # \text 대신 \mathrm
```

- 그림 하나에 메시지 하나. 캡션 첫 문장이 그 메시지다. 호 전체에서 그림 3장 이내.
- 색은 의미로만 쓴다: `ACCENT` 핵심, `WARM` 주의·문제 구간, `GOOD` 정상·정답, 나머지는 회색. 한 그림에 3색 이내.
- 범례 대신 그림 위에 직접 라벨을 단다. 중요한 구간은 옅은 배경색(`*_LIGHT`)으로 칠한다.
- 유형은 내용에 맞게: 곡선·분포(수식의 의미), 흐름도(프레임워크 구조, `FancyBboxPatch`+`FancyArrowPatch`), 시간축 swimlane(동기화·overlap, `broken_barh`), 격자 색칠(layout·tiling).
- 점이 수천 개인 산점도처럼 SVG가 커지는 그림은 피한다 (그림 한 장 250 KB 이하).
- 캡션 끝에 출처를 적는다: "원 논문 Fig. k 재해석" 또는 "직접 작성". 그림 번호는 페이지가 자동으로 붙이니 캡션에 쓰지 않는다.
